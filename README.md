# VintageLite

Приложение для iPhone с iOS 17 или новее. На главном экране и под иконкой отображается VintageLite. Доступ проверяется существующим сервером лицензий. В аккаунте видны оставшийся срок и последние четыре символа ключа.

Раздел «Файлы» загружает все активные записи защищённого каталога, которые возвращает сервер (текущий сервер отдаёт до 300). Открой запись, чтобы прочитать имена и размеры файлов внутри пакета. Проверка пакета и чтение выполняются в памяти. Для доступа нужны действующая лицензия и опубликованные пакеты на сервере. Уже использованный ключ привязан к устройству в системе сервера. Если при обновлении изменилась подпись или идентификатор приложения, администратору может понадобиться проверить существующую привязку.

## Выпуск

Проект использует репозиторий `eremaprivat7-arch/vintagelite-ui-preview`. Сохрани тег `v2.2.0` на коммите с этой версией и отправь его на GitHub. Workflow **VintageLite Release** проверит чтение пакетов на macOS, соберёт приложение, проверит архив и опубликует IPA и SHA-256 в GitHub Releases. Также его можно запустить для ветки `main` через Actions с опцией публикации.

Файл `VintageLite-2.2.0-unsigned.ipa` предназначен для подписи действующим сертификатом и профилем. Идентификатор приложения `dev.eraskye.vintagelite.uipreview` сохранён для обновления поверх предыдущей версии, если подпись и профиль совместимы. Для будущего релиза увеличь `MARKETING_VERSION` и `CURRENT_PROJECT_VERSION`, затем создай соответствующий тег.

Исходное оформление, иконка и протокол лицензирования происходят из `eremaprivat7-arch/vintage-lite`, коммит `598e30c`. Лицензия приведена в `LICENSE`.
